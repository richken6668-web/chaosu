# DEMO 区块链钱包页 SPEC

## 0. 关联信息

- 页面 / 路由 ID：`DEMO-blockchain-wallet` / `/demo/blockchain-wallet`
- 用户类型：前端原型，数字资产持有者
- 设计基底：`src/themes/coinbase/DESIGN.md`
- 原型入口：`index.tsx`

## 原型与正式开发边界

原型模拟资产浏览、余额显隐、地址复制、资产选中、发送/接收弹窗；不连接钱包、不读取链上数据、不执行签名和交易广播。正式开发需接入钱包连接器、行情和链上交易服务。

## 原型数据源

本地静态 ETH、USDC、BTC 资产和演示地址；业务交互状态由本地 React state 驱动。页面级状态分支保留在实现中，但不在原型界面展示状态切换控件。

## Mock 到真实的映射

| Mock | 正式来源 |
|---|---|
| 资产余额/估值 | 链上索引与行情服务 |
| 钱包安全等级 | 钱包安全策略服务 |
| 发送表单 | 地址、余额、手续费和签名校验服务 |
| 接收地址/二维码 | 当前连接钱包与网络 |

## 页面级状态

- PS-01 正常：展示总资产、资产列表、安全信息和走势图。
- PS-02 加载：展示资产内容骨架。
- PS-03 空数据：展示添加第一笔资产的引导。
- PS-04 异常：展示资产加载失败和重试操作。

## 需求与验收映射

| 需求 | 验收标准 |
|---|---|
| US-01 | AC-03-01：总资产、今日变化和余额显隐可见。 |
| US-02 | AC-03-02：点击资产后切换走势图和涨跌徽标。 |
| US-03 | AC-03-03：地址可复制，发送和接收均打开对应弹窗。 |

## 未实现项
