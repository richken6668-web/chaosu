# DEMO 区块链钱包页 PRD

## 用户与目标

目标用户是管理数字资产的个人用户，核心任务是查看资产总额、查看资产明细、复制钱包地址并发起发送或接收流程。

## 范围

- Must：总资产、资产列表、涨跌信息、安全等级、地址复制、发送/接收弹窗。
- Must：显示/隐藏余额，并定义正常、加载、空数据、异常状态与恢复路径；状态切换不作为原型界面内容。
- 不做：真实签名、链上广播、私钥托管、法币交易和 KYC 流程。

## 真实数据交互逻辑

正式产品应通过钱包连接器读取地址、网络、代币余额和行情；发送前需校验链、地址、余额、手续费和用户签名，接收仅展示当前网络地址和二维码。

## 原型边界与 mock

当前使用静态资产、本地显示状态和静态地址模拟钱包。发送“继续”只关闭演示弹窗，不广播交易；地址和余额均不可用于真实交易。
