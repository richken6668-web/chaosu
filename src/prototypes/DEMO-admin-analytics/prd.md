# DEMO 运营数据看板 PRD

## 用户与目标

目标用户是运营负责人和业务分析师，核心任务是查看收入、活跃客户、转化率和退款率，切换指标并定位需要关注的异常。

## 范围

- Must：指标卡、时间范围切换、收入/用户趋势、渠道贡献、关注事项、报告导出入口。
- Must：定义正常、加载、空数据、异常状态与恢复路径；状态切换不作为原型界面内容。
- 不做：实时数仓查询、数据导出生成、告警配置和归因分析。

## 真实数据交互逻辑

正式产品应从指标服务读取带时间范围和时区的聚合数据，标注更新时间与数据新鲜度；导出由异步报表服务生成，异常事项来自告警或规则引擎。

## 原型边界与 mock

当前使用本地数组绘制柱状图和指标卡，时间范围、指标切换只改变展示文本，导出按钮不生成文件。静态数据仅用于验证信息结构。
