# DEMO 运营数据看板 SPEC

## 0. 关联信息

- 页面 / 路由 ID：`DEMO-admin-analytics` / `/demo/admin/analytics`
- 用户类型：后台原型，运营负责人/业务分析师
- 设计基底：`src/themes/stripe/DESIGN.md`
- 原型入口：`index.tsx`

## 原型与正式开发边界

原型模拟指标卡、时间范围切换、收入/用户趋势、渠道占比和关注事项；图表、数据和导出均为本地演示，不能用于财务决策。正式开发需接入指标、数仓、告警和报表服务。

## 原型数据源

本地静态指标与柱状图数组；指标切换和时间范围切换由本地 React state 驱动。页面级状态分支保留在实现中，但不在原型界面展示状态切换控件。

## Mock 到真实的映射

| Mock | 正式来源 |
|---|---|
| 指标卡 | 指标聚合 API |
| 趋势柱状图 | 数仓查询服务 |
| 渠道贡献 | 归因/渠道聚合服务 |
| 关注事项与导出 | 告警规则服务、异步报表服务 |

## 页面级状态

- PS-01 正常：展示指标、趋势、渠道和关注事项。
- PS-02 加载：展示指标和图表骨架。
- PS-03 空数据：展示尚未产生分析数据的引导。
- PS-04 异常：展示加载失败和重试操作。
