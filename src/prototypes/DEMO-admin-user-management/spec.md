# DEMO 用户管理 SPEC

## 0. 关联信息

- 页面 / 路由 ID：`DEMO-admin-user-management` / `/demo/admin/user-management`
- 用户类型：后台原型，工作区管理员
- 设计基底：`src/themes/planhat/DESIGN.md`
- 原型入口：`index.tsx`

## 原型与正式开发边界

原型模拟成员浏览、搜索、角色筛选、成员详情和发送邀请；邀请只展示本地成功反馈，不发送邮件、不变更真实角色和权限。正式开发需接入成员、权限、邀请和审计服务。

## 原型数据源

本地静态成员数组，搜索和角色筛选由本地 React state 计算。页面级状态分支保留在实现中，但不在原型界面展示状态切换控件。

## Mock 到真实的映射

| Mock | 正式来源 |
|---|---|
| 成员列表 | 工作区成员 API，支持分页 |
| 角色/状态徽标 | 权限与成员状态服务 |
| 成员详情 | 成员详情 API |
| 邀请成功 | 邀请服务与邮件服务 |

## 页面级状态

- PS-01 正常：展示成员表格、搜索框、角色筛选和邀请按钮。
- PS-02 加载：展示列表骨架。
- PS-03 空数据：展示无成员引导和邀请按钮。
- PS-04 异常：展示加载失败和重试操作。

## 需求与验收映射

| 需求 | 验收标准 |
|---|---|
| US-07 | AC-05-01：成员姓名、邮箱、角色、状态和活跃时间可见。 |
| US-08 | AC-05-02：输入搜索词或选择角色后列表即时过滤。 |
| US-09 | AC-05-03：点击成员打开详情，邀请弹窗可提交并反馈。 |
