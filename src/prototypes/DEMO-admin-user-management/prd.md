# DEMO 用户管理 PRD

## 用户与目标

目标用户是工作区管理员，核心任务是搜索成员、按角色筛选、查看成员状态和发送邀请。

## 范围

- Must：成员列表、姓名/邮箱搜索、角色筛选、状态徽标、成员详情、邀请成员。
- Must：定义正常、加载、空数据、异常状态与恢复路径；状态切换不作为原型界面内容。
- 不做：真实权限变更、批量导入、SCIM、删除成员和审计导出。

## 真实数据交互逻辑

正式产品应按工作区权限分页读取成员；邀请需要验证邮箱、角色和域策略并发送邀请，角色变更需服务端授权和审计。

## 原型边界与 mock

当前使用本地成员数组模拟搜索、筛选、详情和邀请成功反馈。邀请不会发送邮件，状态不会持久化，也不代表权限已生效。
