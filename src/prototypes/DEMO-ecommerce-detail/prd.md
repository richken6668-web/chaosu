# DEMO 电商详情页 PRD

## 用户与目标

目标用户是移动端购物者，核心任务是理解商品价值、选择尺码和数量，并完成加入购物袋前的确认。

## 范围

- Must：商品主视觉、价格与优惠、尺码选择、数量调整、收藏、加入购物袋、详情/评价切换。
- Must：定义库存、加载、空数据、异常状态与恢复路径；状态切换不作为原型界面内容。
- 不做：真实支付、库存锁定、推荐算法、订单创建和账号体系。

## 真实数据交互逻辑

正式产品应从商品服务读取商品、价格、库存、评价和配送承诺；加入购物袋需要校验 SKU、实时库存和用户会话，并由购物袋服务持久化。

## 原型边界与 mock

当前使用本地静态商品和 React 状态模拟尺码、数量、收藏、评价切换及加入成功反馈。固定商品、价格和成功反馈仅用于演示，不代表正式库存或支付结果。
