# DEMO 电商详情页 SPEC

## 0. 关联信息

- 页面 / 路由 ID：`DEMO-ecommerce-detail` / `/demo/ecommerce-detail`
- 用户类型：前端原型，移动端购物者
- 设计基底：`src/themes/shopify/DESIGN.md`
- 原型入口：`index.tsx`

## 原型与正式开发边界

原型模拟商品浏览、尺码选择、数量调整、收藏、评价切换和加入购物袋反馈；不模拟支付、真实库存、登录或订单写入。正式开发应接入商品、库存、购物袋和评价服务。

## 原型数据源

本地静态商品、价格、尺码、评价和配送文案；业务交互状态由本地 React state 驱动。页面级状态分支保留在实现中，但不在原型界面展示状态切换控件。

## Mock 到真实的映射

| Mock | 正式来源 |
|---|---|
| 商品名称/价格/尺码 | 商品与价格服务 |
| 加入购物袋成功 | 购物袋 API 返回 |
| 评价数量与内容 | 评价服务 |
| 配送与退换承诺 | 履约策略服务 |

## 页面级状态

- PS-01 正常：展示商品内容，可选择尺码、调整数量并加入购物袋。
- PS-02 加载：展示骨架占位，等待商品接口响应。
- PS-03 空数据：展示暂无可售商品，并提供返回商品列表操作。
- PS-04 异常：展示加载失败和重新加载操作。

## 需求与验收映射

| 需求 | 验收标准 |
|---|---|
| US-01 | AC-01-01：价格、优惠、卖点与配送承诺可见。 |
| US-02 | AC-01-02：尺码选中态和数量增减即时反馈。 |
| US-03 | AC-01-03：点击加入购物袋后显示成功反馈。 |
| US-04 | AC-01-04：详情与评价标签可切换。 |

## 未实现项

未实现真实库存校验、支付、登录、购物袋持久化、推荐和服务端错误码处理。
