# DEMO SaaS 平台首页 PRD

## 用户与目标

目标用户是 SaaS 工作区的团队成员和负责人，核心任务是查看工作区健康度、进入项目、查看动态并创建新项目。

## 范围

- Must：工作区导航、核心指标、项目进度、团队动态、待处理事项、新建项目。
- Must：定义正常、加载、空数据、异常状态与恢复路径；状态切换不作为原型界面内容。
- 不做：真实协作编辑、计费、组织权限配置和通知推送。

## 真实数据交互逻辑

正式产品应按当前工作区权限读取项目、成员、任务和活动；创建项目需要服务端校验工作区权限并写入项目、成员和审计日志。

## 原型边界与 mock

当前用本地项目数组和弹窗状态模拟工作区概览与创建成功反馈；不创建服务端项目、不发送通知、不代表真实指标。
