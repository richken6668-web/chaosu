# DEMO SaaS 平台首页 SPEC

## 0. 关联信息

- 页面 / 路由 ID：`DEMO-admin-saas-home` / `/demo/admin/saas-home`
- 用户类型：后台原型，SaaS 工作区成员/负责人
- 设计基底：`src/themes/linear/DESIGN.md`
- 原型入口：`index.tsx`

## 原型与正式开发边界

原型模拟工作区切换、指标查看、项目进度、团队动态、待办和新建项目反馈；新建项目只显示本地成功消息。正式开发需接入工作区、项目、任务、成员和审计服务。

## 原型数据源

本地静态项目、指标、动态和待办；导航和弹窗由本地 React state 驱动。页面级状态分支保留在实现中，但不在原型界面展示状态切换控件。

## Mock 到真实的映射

| Mock | 正式来源 |
|---|---|
| 项目进度与成员数 | 项目与成员服务 |
| 工作区指标 | 任务/活动聚合服务 |
| 团队动态 | 活动流服务 |
| 新建项目 | 项目创建 API 与权限服务 |

## 页面级状态

- PS-01 正常：展示工作区指标、项目进度、动态和待办。
- PS-02 加载：展示主内容骨架。
- PS-03 空数据：展示创建首个项目的引导。
- PS-04 异常：展示数据失败和重试入口。

## 需求与验收映射

| 需求 | 验收标准 |
|---|---|
| US-04 | AC-04-01：侧栏和核心工作区指标可见。 |

| US-06 | AC-04-03：新建项目弹窗可打开并显示创建反馈。 |
