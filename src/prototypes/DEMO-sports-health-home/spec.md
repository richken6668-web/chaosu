# DEMO 运动健康首页 SPEC

## 0. 关联信息

- 页面 / 路由 ID：`DEMO-sports-health-home` / `/demo/sports-health`
- 用户类型：前端原型，个人运动用户
- 设计基底：`src/themes/headspace/DESIGN.md`
- 原型入口：`index.tsx`

## 原型与正式开发边界

原型模拟今日推荐、训练计划、进度切换和开始训练反馈；不提供医疗诊断、不读取设备、不运行真实计时器。正式开发需接入用户档案、训练内容、设备同步和运动记录服务。

## 原型数据源

本地静态训练内容与本地 React state；训练完成次数和计划标签仅用于演示。页面级状态分支保留在实现中，但不在原型界面展示状态切换控件。

## Mock 到真实的映射

| Mock | 正式来源 |
|---|---|
| 今日推荐 | 推荐与训练计划服务 |
| 训练时长/类型 | 内容管理服务 |
| 周/月进度 | 运动记录与目标服务 |
| 开始训练 | 训练会话服务 |

## 页面级状态

- PS-01 正常：展示推荐训练、周进度和三个训练入口。
- PS-02 加载：展示骨架占位，等待推荐和进度数据。
- PS-03 空数据：展示尚未建立计划的引导。
- PS-04 异常：展示加载失败并允许重试。

## 需求与验收映射
