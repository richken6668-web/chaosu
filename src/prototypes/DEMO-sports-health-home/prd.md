# DEMO 运动健康首页 PRD

## 用户与目标

目标用户是希望建立规律运动习惯的个人用户，核心任务是查看今日训练、开始一项练习并了解周/月进度。

## 范围

- Must：今日推荐、训练卡片、训练计划、进度概览、开始训练反馈。
- Must：定义正常、加载、空数据、异常状态与恢复路径；状态切换不作为原型界面内容。
- 不做：健康诊断、设备同步、真实运动计时、医疗建议和会员支付。

## 真实数据交互逻辑

正式产品应根据用户档案、训练计划、设备数据和完成记录生成今日推荐；开始训练创建训练会话，完成训练写入运动记录并更新目标进度。

## 原型边界与 mock

当前用静态训练卡片、本地完成次数和标签切换模拟推荐与进度。训练开始只改变本地展示，不计时、不采集健康数据，也不代表医疗结论。
